Using AI Ethically in Our Class

A guide to using AI as a powerful learning tool.

The Core Principle: You Are the IT Professional

Generative AI (like ChatGPT, Gemini, Copilot, etc.) is an incredibly powerful tool for technology professionals. In this class, we will learn to use it as an assistant to help us understand complex systems, troubleshoot issues, and improve our own work. The most important rule is that **the work you submit must be the product of your own intellect and effort.** Submitting a script, configuration, or report generated by an AI to solve a problem for you is plagiarism.

✅

Green Light: Ethical Use (Using AI as an Assistant)

You are **encouraged** to use AI for the following tasks:

  • Explaining Concepts: Ask the AI to explain a technical concept (like "the OSI model" or "RAID levels") with an analogy.
  • Troubleshooting Errors: Paste a cryptic error message from a script or command line and ask for a plain-language explanation of what it means.
  • Generating Boilerplate: Ask the AI to generate the basic starting structure for a script (e.g., "give me a basic PowerShell script template with parameter handling").
  • Brainstorming Solutions: Describe a problem (e.g., "I need to check if a service is running on 100 servers") and ask the AI to suggest different tools or approaches (like PowerShell, Ansible, or Bash).
  • Refining Technical Writing: After you've written a report or documentation, ask the AI to check it for clarity, grammar, and spelling.
❌

Red Light: Unethical Use (Using AI as the Problem-Solver)

You are **not permitted** to use AI for the following tasks:

  • Generating Solutions: Do not provide an AI with the requirements of a lab or assignment and ask it to write the script or configuration for you.
  • Fixing Your Work For You: Do not paste a broken script or configuration and ask the AI to "fix it." Use it to understand the *error*, then apply the fix yourself.
  • Writing an Entire Report: Do not ask the AI to write your technical analysis, documentation, or reports.
  • Answering Quiz Questions: Do not use AI to answer questions on quizzes or exams.

Practical Prompts for Ethical AI Use

The key to using AI effectively is in how you ask. You want a coach, not a ghostwriter.

For Understanding a Command:

Instead of: "Write a bash script to find all files larger than 10MB."

Try This: "Can you explain the different parts of this bash command: `find . -type f -size +10M`? What does each flag do?"

For Improving Your Work:

Instead of: "Make this PowerShell script better."

Try This: "Here is my working PowerShell script that pings a list of servers. Are there ways to make it more efficient, like running the pings in parallel? Please explain the concepts you suggest."
